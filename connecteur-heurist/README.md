Connecteur Heurist — ArchiBarthes

Ce dossier conserve une copie du chargeur JavaScript installé dans la page Atlas du CMS Heurist.

Fonctionnement : Heurist exécute le chargeur, qui appelle atlas/main.js sur GitHub Pages. Ce dernier charge les différents modules de l'Atlas.

Maintenance : les modifications des visualisations se font dans les fichiers du dossier atlas/ et dans les autres modules du dépôt. Le chargeur ne doit pas être modifié tant que l'adresse de atlas/main.js reste identique.

Attention : modifier ce fichier sur GitHub ne modifie pas automatiquement le code enregistré dans Heurist.
